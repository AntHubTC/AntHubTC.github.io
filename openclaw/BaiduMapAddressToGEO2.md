# 百度地图地址转坐标 Skill — 商业价值说明

## 一、Skill 简介

本 Skill 是一个**自然语言地址转坐标工具**，用户只需输入自然语言描述（如"成都肯德基"、"成都市所有超市"），即可通过百度地图开放平台 API 批量查询目标 POI（兴趣点）的精确经纬度坐标，并以结构化表格 + Excel 文件输出结果。

**核心能力：** 自然语言 → 地址拆解 → 百度地图 API 查询 → 经纬度坐标 + POI 信息 → Excel 交付。

---

## 二、公司背景与业务痛点

公司是中国领先的**电梯智能屏广告公司**，在全国数十万部电梯中部署了智能屏终端，为品牌客户提供基于**楼盘（住宅社区）**的精准广告投放服务。

### 核心业务逻辑

```
品牌客户想投放广告
        ↓
广告素材需要展示在目标人群的电梯智能屏上
        ↓
电梯屏与"楼盘"绑定，楼盘有经纬度坐标
        ↓
关键问题：如何快速找到"符合品牌投放需求"的楼盘？
        ↓
答案：以品牌门店/竞品门店/商圈的坐标为中心
     + 设定辐射半径（如1km、3km）
     = 自动匹配覆盖范围内的所有楼盘
     = 精准出量、精准出方案
```

### 痛点：人工询量效率低

传统方式下，销售/运营人员接到品牌客户的投放需求后，需要：

1. **手动确认品牌门店位置**（在地图上一个一个找）
2. **手动记录经纬度**（逐个复制粘贴）
3. **逐一匹配楼盘**（用坐标 + 半径在系统中查询）
4. **汇总报价方案**（整合多个点位的数据）

这个过程**耗时长、易出错、难规模化**。当客户说"我想在成都所有肯德基门店周边3公里投放广告"时，成都可能有上百家肯德基门店——人工逐个查找完全不现实。

## 三、本 Skill 的解决方案

### 核心链路

```
用户输入："成都肯德基 地址转坐标"
        ↓
  Skill 自动调用百度地图 API
        ↓
  返回成都所有肯德基门店的经纬度坐标
        ↓
  坐标 + 半径 → 查询内部系统匹配楼盘
        ↓
  输出：覆盖范围内的所有楼盘点位清单
        ↓
  结果：精准广告投放方案
```

### 关键价值

| 价值维度 | 说明 |
|---------|------|
| **效率提升** | 从"人工逐个找门店坐标"变为"一句话批量获取所有坐标"，查询时间从小时级降至秒级 |
| **覆盖更全** | 百度地图 POI 数据覆盖全国，能找到人工容易遗漏的偏远门店、新开店 |
| **可批量** | 一次查询可获取整座城市的某品牌全部门店坐标，支持多品牌、多品类同时查询 |
| **可追溯** | 输出 Excel 文件，坐标数据留档，方便复核和二次使用 |
| **自然语言交互** | 销售人员无需学习工具，用日常语言描述需求即可 |

## 四、商业场景

### 场景一：品牌客户门店辐射投放（核心场景）

**需求来源：** 肯德基、麦当劳、星巴克、瑞幸等连锁品牌希望在自家门店周边的住宅社区电梯屏投放品牌广告，增强消费者认知、促进到店转化。

**操作示例：**
- 输入："成都肯德基 地址转坐标"
- 获得：成都所有肯德基门店的经纬度（可能 100+ 条）
- 后续：每条坐标 + 1~3km 半径 → 匹配内部楼盘 → 输出投放方案
- 交付给客户："您的广告将覆盖成都所有肯德基门店周边 2 公里内的 1,200 个楼盘，触达约 350 万户家庭"

### 场景二：竞品门店拦截投放

**需求来源：** 品牌客户希望在竞品门店附近投放广告，实现"消费者出门看到广告，转角就进我家门店"的拦截效果。

**操作示例：**

- 客户：汉堡王（想拦截麦当劳客流）
- 输入："成都麦当劳 地址转坐标"
- 获得：所有麦当劳门店坐标
- 投放策略：在麦当劳门店周边 1.5km 的电梯屏投放汉堡王广告
- 商业话术："您的广告将在竞品门店步行 15 分钟范围内的电梯屏循环播放"

### 场景三：新店开业预热投放

**需求来源：** 连锁品牌即将在某城市新开门店，希望在开业前 1-2 周在周边住宅社区进行广告预热，提升开业当日客流。

**操作示例：**
- 输入："成都市武侯区XXX广场 地址转坐标"
- 获得：新店精确坐标
- 匹配：以该坐标为中心 3km 半径内所有楼盘
- 投放时间：开业前 2 周至开业后 1 周
- 效果：精准触达周边居民，提升开业 awareness

### 场景四：行业/品类批量拓客

**需求来源：** 公司销售团队需要向某一行业的客户批量推介广告服务，需要快速了解该行业在目标城市的门店分布和潜在覆盖规模。

**操作示例：**

- 输入："成都健身房 地址转坐标" / "成都奶茶店 地址转坐标" / "成都培训机构 地址转坐标"
- 获得：该品类所有门店的坐标和数量
- 价值：
  - 生成行业报告："成都市共有 860 家健身房门店，覆盖周边 3,200 个楼盘"
  - 批量生成投放方案，统一向健身行业客户推介
  - 销售话术有据可依，提升转化率

### 场景五：商圈/区域广告覆盖评估

**需求来源：** 品牌客户希望在特定商圈（如春熙路、天府广场、万象城周边）投放广告，需要评估该商圈内有多少楼盘、覆盖多少家庭。

**操作示例：**
- 输入："成都春熙路 地址转坐标" / "成都万象城 地址转坐标" / "成都银泰中心 地址转坐标"
- 获得：核心地标坐标
- 匹配：以各坐标为中心，半径 2~5km 内所有楼盘
- 评估报告：商圈广告覆盖度、触达人群规模、点位库存
- 用途：销售提案中的"商圈投放方案"板块

### 场景六：城市拓展规划

**需求来源：** 公司计划进入新城市或扩大现有城市的覆盖范围，需要评估目标区域的商业 POI 密度和楼盘匹配情况。

**操作示例：**
- 输入："重庆主城区肯德基 地址转坐标" + "重庆主城区星巴克 地址转坐标" + "重庆主城区大型商超 地址转坐标"
- 获得：新城市的商业 POI 分布图
- 分析：POI 密度高的区域 = 商业活跃区 = 广告价值高的区域
- 决策：优先在 POI 密集区域拓展电梯屏覆盖

### 场景七：精准人群定向投放

**需求来源：** 不同 POI 周边的楼盘，其居民画像不同，可据此实现人群定向。

**操作逻辑：**

| POI 类型 | 周边楼盘人群特征 | 适合的广告主 |
|----------|---------------|-------------|
| 幼儿园、小学、培训机构 | 有孩家庭（25-45岁） | 母婴用品、教培、亲子乐园 |
| 写字楼密集区 | 职场白领 | 互联网产品、金融理财、外卖平台 |
| 大型商超、购物中心 | 消费型家庭 | 快消品、家电、家居建材 |
| 医院、药店周边 | 中老年家庭 | 保健品、医疗器械、养老服务 |
| 大学周边 | 学生/年轻租户 | 奶茶、快餐、数码产品 |
| 高端商场、五星级酒店 | 高收入群体 | 奢侈品、高端汽车、金融 |

**操作示例：**
- 输入："成都幼儿园 地址转坐标"
- 获得：所有幼儿园坐标
- 匹配周边楼盘 → 标记为"家庭型社区"
- 输出方案："母婴品牌投放方案 — 覆盖成都 2,800 个家庭型社区"

### 场景八：广告效果归因分析

**需求来源：** 广告投放后，客户希望验证"广告是否真的带来了门店客流提升"。

**操作逻辑：**
1. 投放前：获取品牌门店坐标，匹配周边楼盘，执行电梯屏广告投放
2. 投放中：持续监控投放区域的楼盘覆盖
3. 投放后：分析门店客流变化与广告覆盖区域的重合度
4. 输出归因报告："覆盖楼盘内居民到店率提升了 X%"

### 场景九：点位询量自动化（日常高频场景）

**需求来源：** 销售在给客户报价前，需要快速知道"某个区域内有多少可用的电梯屏点位"。

**操作流程：**
1. 销售接到客户需求："在成都高新区 3km 范围内投放"
2. 输入："成都高新区 地址转坐标" → 获取高新区核心坐标
3. 以坐标为中心 + 半径 → 自动查询内部系统
4. 秒级返回：点位数量、覆盖楼盘数、预估触达人数
5. 快速生成报价方案

### 场景十：跨行业客户联合方案

**需求来源：** 创新的"联合投放"方案 — 将关联行业的广告在同一批楼盘中展示。

**操作示例：**
- 输入："成都全屋定制 地址转坐标" + "成都家居卖场 地址转坐标"
- 匹配重叠楼盘 → 这些楼盘的居民正在装修/购房
- 方案：在同一批楼盘中同时投放家居卖场 + 全屋定制广告
- 商业价值：打包售卖，提升客单价
